# Prøvematerialer

Repository indeholder [kildemanifestet](fp9/sources.json) med filnavne,
downloadkilder, størrelser og SHA-256 for de undersøgte danske FP9-filer.
De downloadede PDF'er og regneark ligger kun lokalt i `fp9/` og er ignoreret af
Git. Prototypen kræver dem ikke for at starte.

En ny klon indeholder derfor ikke selve prøvesættene. Ved behov kan filerne
hentes manuelt fra manifestets kilder og gemmes med de angivne filnavne.
Kontrollér SHA-256 mod manifestet; links kan ændres efter researchdatoen.

AEU-2-materialerne er i en separat privat samling. Stier i
[filoversigten](../research/FOUND-EXAMS.csv) er relative til denne samlings rod,
ikke til repository. Oprindelige maskinspecifikke stier er bevaret lokalt i
`.local/FOUND-EXAMS.csv` og indgår ikke i Git.
